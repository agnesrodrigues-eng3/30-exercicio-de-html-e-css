1. Introdução ao Desenvolvimento Web

O h1 representa o título princípal de uma página, sendo ele a infromação mais importante do site utilizado uma unica vez, sem ocorrer repetição.

1.1 O que é HTML?

HTML é a linguagem utilizada para estruturar o conteúdo de uma página web.

1.1.1 Extrutura de uma página HTML

Uma página HTML possui elementos que organizam seu conteúdo e sua estrutura.

1.1.1.1 Elementos HTML

Os elementos HTML são utilizados para representar diferentas partes do conteúdo de uma página

1.1.1.1.1 Títulos e parágrafos

Títulos e parágrafos ajudam a organizar e apresentar as informações de maneira hierárquica.
