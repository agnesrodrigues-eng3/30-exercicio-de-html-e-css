Elementos relacionados a citações famosas em HTML

Utilização do elemento <blockquote>

O elemento <blockquote> é utilizado para representar uma citação extensa que foi retirada de outra fonte.

Utilização do elemento <q>

O elemento <q> é utilizado para representar citações curtas inseridas dentro de um texto. O navegador geralmente adiciona as aspas automaticamente.

René Descartes destacou a importância do pensamento e da razão para compreender a própria existência.

Uma de suas frases mais conhecidas é: Penso, logo existo.

Autor: René Descartes

Autor: Mahatma Gandhi

Utilização do elemento <abbr>

O elemento <abbr> é utilizado para representar abreviações. Ao posicionar o cursor sobre a abreviação, o significado completo pode ser apresentado ao usuário.
