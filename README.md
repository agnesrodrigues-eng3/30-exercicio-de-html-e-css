# 📚 Exercícios de HTML, CSS e JavaScript

## 💻 Sobre o projeto

Este repositório contém **30 exercícios práticos** desenvolvidos durante meus estudos de **Desenvolvimento Web**.

O objetivo é colocar em prática os conceitos aprendidos em **HTML, CSS e JavaScript**, evoluindo desde estruturas básicas de páginas até projetos mais completos.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📌 Conteúdos praticados

* Estrutura básica do HTML
* Títulos, textos e formatação
* Links e imagens
* Listas e tabelas
* Formulários
* Seletores CSS
* Cores e fontes
* Backgrounds
* Box Model
* Organização e estilização de páginas
* Introdução ao JavaScript
* Lógica de programação

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado na área de tecnologia e representa minha evolução na construção de páginas web e na aplicação dos fundamentos de programação.
